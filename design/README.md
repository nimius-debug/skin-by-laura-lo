# Source images

Masters and originals. This directory is NOT served — only `public/` is
published to Cloudflare's asset layer, so nothing here is uploaded to the
edge or reachable over the web.

`laura-hero-source.jpg` is the original studio photo. The hero cutout in
`public/media/laura-hero.webp` was derived from it with u2net segmentation
plus alpha matting; regenerate from this file if the crop or framing needs
to change.
